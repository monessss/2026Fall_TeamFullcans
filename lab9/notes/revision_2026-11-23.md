## Runtime integrity and reproduction

- ORB launcher uses an isolated working directory and rejects nonzero exits or
  missing new output. Previous exported output cannot mask a failed run.
- Host runners validate output before replacing archived trajectories. A future
  LDSO run exits naturally without being killed when an output file appears.
- New runs record exit status, input-file count where available, and file hashes.
  Runtime logs in this lab are no longer excluded by the broad root log rule.
- Default Docker paths use the current host; nested Docker requires explicit
  host-path mappings. Existing running containers are not silently stopped.
- LDSO and future ORB builds pin source revisions. The historical ORB image
  revision was not recorded and is not reconstructed from the new pin.
- evaluate.sh --results permits re-evaluation without images or Docker.
